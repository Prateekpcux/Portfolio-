The Problem

Discoverability was the symptom.
Trust was the disease.

Before Periscope

Six platforms. Zero coherence.

  • Power BI · Tableau · Signal 1 · Vizient · Epic · SharePoint - no shared taxonomy
  • Duplicate reports everywhere - no one knew which version was official
  • Users emailed the analytics team before trusting any asset
  • AI models with no governance, oversight, or expiry tracking
  • New employees had no onboarding path into analytics
High bounce off stale reports Duplicate work Low data trust
The Mandate

One governed marketplace. Every asset. Trusted.

  • Unified search + browse across all six platforms and asset types
  • Certification state visible on every asset card - not buried in metadata
  • Dedicated AI model inventory with oversight, performance, and approval chain
  • Campaigns path for clinical users who think in outcomes, not taxonomies
  • Governance workflows for admins - certify, deprecate, manage lifecycle

Critical Decisions

Three calls that shaped the platform.

Research surfaced the findings. These three decisions are what we did with them.

01

Governance visible at card level - not detail page

  • Early prototypes: certification buried in metadata tab
  • Users scrolled past it every single time
  • Fix: elevated to card surface - status badge, owner, last validated visible at browse time
→ Trust at browse time
02

Campaigns - a parallel browse path for clinical users

  • Clinical users think in initiatives, not data taxonomies
  • Taxonomy browse failed them in every session
  • Fix: Campaign path groups assets by HIMSS, Cost Reduction, Heart Failure
→ 2× faster time-to-asset for clinical users
03

AI models treated as first-class assets, not a filter

  • Initial scope: AI = one asset type in the filter panel
  • AI carries oversight obligations no other asset has
  • Fix: dedicated inventory with performance, expiry, bias review, oversight chain
→ Inova's first AI governance UX

Information Architecture

Two browse paths. One front door.

Taxonomy for developers who think by tool and data domain. Campaigns for clinical managers who think by initiative. Same IA, two valid entry points - neither compromised for the other.

Low-Fidelity → Hi-Fidelity

Layout first. Trust language second.

Low-fi locked the navigation structure and layout logic across 4 sprints. Hi-fi resolved the governance signals - certification badges, ownership, last validated dates - that make users feel confident in what they find.

Design System

Built on Inova's foundation.
Extended for governance.

Periscope was built entirely within Inova's enterprise design system - Arial typeface, semantic color tokens, and established component patterns. My job wasn't to invent new styles; it was to extend the system with patterns a marketplace needed that didn't exist yet.

Asset Cards

Trust-first browse tile - certification badge, tool source icon, owner, last validated date all visible before clicking

AI Model Cards

Performance state, certification expiry countdown, bias review flag - no equivalent in the base system

Governance Chips

6-state certification system mapped to Inova semantic tokens: Certified, In Review, Expired, Pending, Deprecated, Flagged

Campaign Tiles

Initiative-grouping pattern built from existing card components, new hero image treatment for clinical pathways

Extended Patterns Added to System
Certified
Visible on card surface - green badge, owner, last validated
In Review
Blue indicator - governance workflow in progress
Expired / Flagged
Red - visible before user opens asset, not after
Deprecated
Grey - surfaced in search to redirect, not hide
Outcomes

Two numbers. Both earned.

68%
Faster time-to-find an asset
How we measured it
  • →Timed task: find a specific certified dashboard in the old system (Power BI + SharePoint + Teams) vs Periscope
  • →Old system avg: 6.2 min. Periscope avg: 2.0 min - across 3 rounds of moderated testing
  • →The driver: governance status on the card meant users stopped second-guessing which asset to trust
20K+
Active users at launch
How we got there
  • →Replaced Power BI, Tableau, Signal 1, Vizient, Epic, and SharePoint in a single Phase 1 deployment
  • →Clinical users adopted via Campaigns - found audit assets without learning a new taxonomy
  • →Zero formal training sessions required - the experience was intuitive enough to self-onboard

Periscope moved Inova from fragmented report hunting to a governed, searchable, trust-aware marketplace. The real design challenge wasn't making assets easier to find - it was making every user feel confident that what they found was certified and appropriate for clinical decision-making.

Next Steps
  • Moderated usability testing with 5 clinical users post-launch
  • A/B testing - search placement + card layout variants
  • UAT validation + dev sprint support
  • Iterative feedback loops to refine based on real usage
What I'd Do Differently
  • Push for moderated user research before Sprint 1, not after
  • 5 clinical users early would've validated trust-first cards 2 sprints sooner
  • Stakeholder input was strong - but real users would've accelerated decision confidence
