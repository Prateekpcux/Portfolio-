The Problem

Discoverability was the symptom. Trust was the disease.

Before Periscope

5 platforms. Zero coherence.

  • Analytics spread across Power BI, Tableau, Signal 1, Vizient, Epic, SharePoint
  • No shared taxonomy — duplicate reports everywhere
  • No certification visibility — users emailed the team before trusting any asset
  • AI models existed with no governance, oversight, or expiry tracking
  • New employees had no onboarding path into analytics
High bounce off stale reports Duplicate work Low trust in data
The Mandate

One governed marketplace. Every asset. Trusted.

  • Unified search + browse across all platforms and asset types
  • Certification state visible on every asset card — not buried in metadata
  • AI model inventory with oversight, performance, and approval chain
  • Initiative-based Campaigns for clinical users who think in outcomes
  • Governance workflows for admins — certification, deprecation, lifecycle

Critical Decisions

Three calls that shaped the platform.

01

Governance visible at card level — not detail page

  • Early: certification buried in metadata tab
  • Users scrolled past it every time
  • Fix: elevated to the card surface — status badge, owner, last validated
→ Trust at browse time
02

Campaigns — parallel browse for clinical users

  • Clinical users think in initiatives, not taxonomies
  • Taxonomy browse failed them in user testing
  • Fix: Campaign path groups assets by HIMSS, Cost Reduction, Heart Failure
→ 2× faster time-to-asset
03

AI models — first-class assets, not a tab

  • Initial scope: AI = one asset type filter
  • AI carries oversight obligations no other asset has
  • Fix: dedicated inventory with performance, expiry, bias review
→ Inova's first AI governance UX

Periscope transformed data governance from a back-office function into a discoverable, trusted, user-centered enterprise product. The deepest design challenge wasn't search — it was making every user feel confident that what they found was certified and appropriate for clinical decision-making.

Next Steps
  • Moderated usability testing with 5 clinical users
  • A/B testing — search placement + card layout variants
  • UAT validation + dev sprint support
  • Iterative feedback loops post-launch
What I'd Do Differently
  • Push for user research before Sprint 1, not after
  • 5 clinical users early would've validated trust-first cards 2 sprints sooner
  • Stakeholder input was strong — but real users would've accelerated confidence
